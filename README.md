# 具身智能操作数据管理系统

Embodied Operating Data System

这个项目面向机器人操作任务的数据整理。第一版先处理离线文件：把一次操作产生的元数据、视频和状态序列放在一起，检查文件是否齐全，再把通过检查的记录导出成固定版本。

首个场景是桌面抓取和物体搬运。系统不直接控制机器人，也不负责训练模型。开发阶段会使用明确标记的合成样例，不把样例当成真实设备采集结果。

## 使用场景

采集文件通常散落在不同目录里。任务名称、设备、视频和状态序列很容易失去对应关系，后面做筛选时只能靠人工翻文件夹。

系统希望把这条流程固定下来：

**创建项目 → 导入批次 → 检查记录 → 人工标记 → 固定数据集版本 → 导出**

## 首版功能

- 管理项目、任务和操作记录。
- 按 JSON 清单导入元数据及关联文件。
- 按任务、设备、时间和操作结果筛选记录。
- 查看视频、状态数据摘要及缺失文件。
- 检查必填字段、文件存在性、时间范围和序列时间戳。
- 标记成功、失败或待确认，并记录修改历史。
- 根据选定记录生成数据集版本。
- 导出清单、质量报告和关联文件，并保存文件校验值。

首版暂不处理机器人实时控制、在线流式采集、模型训练、视频逐帧标注和多租户权限。

## 数据对象

一次操作记录（Episode）是系统里的基本单位。项目下面有任务，任务下面可以有多次操作记录。

| 对象 | 说明 |
| --- | --- |
| Project | 项目名称、描述和创建时间 |
| Task | 操作目标、任务名称和场景 |
| ImportBatch | 文件来源、导入时间和逐条结果 |
| Episode | 设备、起止时间、操作结果和来源 |
| Asset | 关联文件的路径、类型、大小和校验值 |
| QualityReport | 检查规则、问题明细和检查时间 |
| AnnotationRevision | 人工标记的前后值和修改时间 |
| DatasetVersion | 样本集合、元数据快照和生成时间 |

首版拟支持 JSON、MP4 和 CSV。导入字段、时间单位和文件路径规则会在实现导入模块时单独固定。

原始文件与人工标记分开保存。生成数据集版本时保存元数据快照和文件校验值；源文件发生变化时，导出应报错，而不是悄悄替换内容。
